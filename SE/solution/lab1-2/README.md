# Лабораторная работа 1-2: BPMN-моделирование бизнес-процессов

**Вариант:** 10 — Библиотека
**Инструмент:** Visual Paradigm

## Задание

1. Выбрать 3 бизнес-процесса из предметной области ✅ (выбрано: регистрация читателя, выдача книги, пополнение фонда)
2. Написать текстовые описания по шаблону ✅ (готово в `processes.md`)
3. Построить BPMN-модели для 3 процессов в Visual Paradigm ⏳

## Пошаговая инструкция

### Шаг 1. Установка Visual Paradigm

1. Скачайте Visual Paradigm Community Edition с https://www.visual-paradigm.com/download/
2. Установите программу
3. Запустите Visual Paradigm

### Шаг 2. Создание проекта

1. В меню выберите `File` → `New Project`
2. Выберите `Business Process Diagram` (BPMN)
3. Назовите проект, например `Library_Processes`

### Шаг 3. Построение BPMN-модели для процесса 1 (Регистрация читателя)

1. Откройте файл `processes.md` и прочитайте описание процесса «Регистрация читателя»
2. В Visual Paradigm используйте следующие элементы:
   - **Start Event** (круг) — начало процесса (Обращение посетителя)
   - **Task** (прямоугольник со скруглёнными углами) — действия (Проверка абонемента, Регистрация данных, Создание карточки и т.д.)
   - **Exclusive Gateway** (ромб) — развилки (Если абонемент отсутствует)
   - **End Event** (круг с толстой линией) — конец процесса (Вариант 1 или Вариант 2)
   - **Sequence Flow** (стрелка) — связи между элементами
3. Постройте диаграмму согласно описанию в `processes.md`
4. Добавьте тайминги к задачам (можно в виде текста на диаграмме)

### Шаг 4. Построение BPMN-модели для процесса 2 (Выдача книги)

1. Создайте новую BPMN-диаграмму: `Diagram` → `New Diagram` → `Business Process Diagram`
2. Назовите её `Book_Lending`
3. Постройте диаграмму по описанию «Выдача книги» из `processes.md`
4. Используйте те же элементы: Start Event, Task, Exclusive Gateway, End Event, Sequence Flow

### Шаг 5. Построение BPMN-модели для процесса 3 (Пополнение библиотечного фонда)

1. Создайте новую BPMN-диаграмму: `Diagram` → `New Diagram` → `Business Process Diagram`
2. Назовите её `Fund_Replenishment`
3. Постройте диаграмму по описанию «Пополнение библиотечного фонда» из `processes.md`

### Шаг 6. Сохранение скриншотов

1. Для каждой диаграммы сделайте скриншот
2. Сохраните скриншоты в папку `img/` с именами:
   - `registration.png` — регистрация читателя
   - `lending.png` — выдача книги
   - `replenishment.png` — пополнение фонда
3. Формат: PNG или JPG

## Элементы BPMN 2.0

| Элемент | Обозначение | Назначение |
|---------|-------------|------------|
| Start Event | Круг (тонкая линия) | Начало процесса |
| End Event | Круг (толстая линия) | Завершение процесса |
| Task | Прямоугольник со скруглёнными углами | Действие/операция |
| Exclusive Gateway | Ромб с X | Развилка (только один путь) |
| Sequence Flow | Стрелка | Порядок выполнения |
| Pool | Прямоугольник (контейнер) | Участник процесса |
