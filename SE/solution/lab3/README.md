Лабораторная работа №3
Построение диаграммы прецедентов в Visual Paradigm CE
Вариант 6 — «Библиотека»

Состав диаграммы
| Элемент | Что добавить |
|---------|-------------|
| Проект / диаграмма | Library / LibraryService |
| Система (System) | «Система обслуживания читателей библиотеки» |
| Актёры (Actor) | Читатель; Библиотекарь; Регистратор |
| Основные прецеденты | «Зарегистрироваться в библиотеке»; «Получить книгу» |
| Включаемые (Include) | «Проверить абонемент»; «Записать выдачу»; «Проверить наличие книги»; «Вернуть книгу» |
| Расширяющие (Extend) | «Продлить абонемент»; «Поставить книгу в очередь» |

Шаг 1. Создать проект
1. Запустить Visual Paradigm CE.
2. В верхнем меню открыть вкладку Project и нажать New.
3. В поле Name ввести Library, в поле Author — свою фамилию.
4. Нажать Create Blank Project.
[Скриншот] Окно создания проекта.

Шаг 2. Создать диаграмму
1. Открыть вкладку Diagram и нажать New.
2. В строке поиска набрать use case.
3. Выбрать Use Case Diagram и нажать Next.
4. В поле Diagram Name ввести LibraryService.
5. Нажать OK.
[Скриншот] Окно с именем диаграммы.

Шаг 3. Добавить границу системы
1. На панели фигур слева выбрать System.
2. Кликнуть в центре рабочей области.
3. Ввести название «Система обслуживания читателей библиотеки» и нажать Enter.
4. Растянуть прямоугольник за угловые маркеры: внутри должны поместиться 8 прецедентов.
[Скриншот] Сделать скриншот.

Шаг 4. Добавить актёров
1. Выбрать Actor, кликнуть слева от системы, ввести «Читатель», нажать Enter.
2. Выбрать Actor, кликнуть справа вверху, ввести «Библиотекарь», нажать Enter.
3. Выбрать Actor, кликнуть справа внизу, ввести «Регистратор», нажать Enter.
[Скриншот] Сделать скриншот.

Шаг 5. Добавить основные прецеденты
1. Выбрать Use Case, кликнуть в верхней половине системы, ввести «Зарегистрироваться в библиотеке».
2. Выбрать Use Case, кликнуть в нижней половине, ввести «Получить книгу».
3. Если текст не помещается — растянуть овал.

Шаг 6. Связать актёров с прецедентами (Association)
Провести 4 связи:
| Актёр | Прецедент |
|-------|-----------|
| Читатель | Зарегистрироваться в библиотеке |
| Регистратор | Зарегистрироваться в библиотеке |
| Читатель | Получить книгу |
| Библиотекарь | Получить книгу |

Как провести одну связь:
1. Навести курсор на актёра — в правом верхнем углу появится значок Resource Catalog.
2. Зажать этот значок и протянуть линию до нужного прецедента.
3. Отпустить кнопку мыши и выбрать Association.

Запасной способ: выбрать Association на панели, кликнуть по актёру, затем по прецеденту.
[Скриншот] После всех четырёх связей.

Шаг 7. Задать кратность
Для каждой из четырёх ассоциаций:
1. Дважды кликнуть по концу линии возле актёра — откроется окно Association End From.
2. Ввести 1.
3. Нажать кнопку со стрелкой вправо — откроется другой конец связи.
4. Ввести *.
5. Нажать зелёную галочку.
[Скриншот] Окно задания кратности и результат.

Шаг 8. Добавить дополнительные прецеденты
С помощью Use Case добавить внутрь системы 6 овалов:
- Над «Зарегистрироваться в библиотеке» — один овал: «Проверить абонемент».
- Над «Получить книгу» — три овала в ряд: «Проверить наличие книги», «Записать выдачу», «Вернуть книгу».
- Между двумя основными прецедентами — «Продлить абонемент».
- Под «Получить книгу» — «Поставить книгу в очередь».
[Скриншот] Сделать скриншот.

Шаг 9. Связи Include
1. На панели фигур выбрать Include.
2. Кликнуть сначала по основному прецеденту, затем по включаемому. На стрелке появится подпись «Include».

| От (основной) | К (включаемый) |
|--------------|----------------|
| Зарегистрироваться в библиотеке | Проверить абонемент |
| Получить книгу | Проверить наличие книги |
| Получить книгу | Записать выдачу |
| Получить книгу | Вернуть книгу |

[Скриншот] Сделать скриншот.

Шаг 10. Связи Extend
1. На панели фигур выбрать Extend.
2. Кликнуть сначала по расширяющему прецеденту, затем по основному. Стрелка пойдёт к основному.

| От (расширение) | К (основной) |
|----------------|--------------|
| Продлить абонемент | Зарегистрироваться в библиотеке |
| Поставить книгу в очередь | Получить книгу |

Если появится окно выбора extension point — нажать OK. У основных прецедентов появится секция extension points.

Смысл связей: абонемент продлевают по желанию; книгу ставят в очередь только если её нет в наличии. Пригодится для пояснений в отчёте.
[Скриншот] Сделать скриншот.

Шаг 11. Оформление (по желанию)
- Цвет фигуры: правый клик по фигуре → Styles and Formatting → Formats → Background, выбрать цвет, нажать OK.
- Если линии пересекаются — перетащить середину линии, чтобы появился изгиб.
- Выровнять фигуры, чтобы стрелки не перекрывали надписи.

Шаг 12. Экспорт и сохранение
1. Нажать Ctrl+A — выделить всю диаграмму.
2. Нажать Ctrl+Alt+C — скопировать её картинкой.
3. Вставить в Word (Ctrl+V).
4. Сохранить проект: Project → Save, файл Library.vpp.

Примерный вид итоговой диаграммы

```
                    Проверить абонемент
                          «include»
               Зарегистрироваться в библиотеке
                          «extend»
                        Продлить абонемент

Читатель     1 *  Система обслуживания читателей библиотеки  * 1  Регистратор
                Проверить наличие книги  Записать выдачу  Вернуть книгу
                          «include»       «include»      «include»
                         Получить книгу
                          «extend»
                     Поставить книгу в очередь

                 * 1  Библиотекарь
```

Проверка результата
- 3 актёра стоят снаружи системы.
- 8 прецедентов стоят внутри системы.
- 4 ассоциации, у каждой кратность 1 и *.
- 4 связи «Include», стрелки направлены от основного прецедента.
- 2 связи «Extend», стрелки направлены к основному прецеденту.

Ответы на контрольные вопросы
1. Для чего используется диаграмма прецедентов?
Она описывает функциональные требования к системе: что система делает с точки зрения внешних пользователей (актёров), без деталей реализации. Используется на этапе анализа требований и для общения с заказчиком.

2. Основные элементы диаграммы прецедентов:
- актёр (Actor) — внешний участник: человек или другая система;
- прецедент (Use Case) — действие, которое система выполняет для актёра;
- граница системы (System);
- отношения: ассоциация (Association), включение (Include), расширение (Extend), обобщение (Generalization).

3. Как создать диаграмму в Visual Paradigm CE:
1. Project → New → Create Blank Project.
2. Diagram → New → Use Case Diagram → Next, ввести имя, OK.
3. С панели фигур добавить System, Actor и Use Case.
4. Связи провести через Resource Catalog или инструментами Association, Include, Extend.
5. Сохранить проект: Project → Save.
