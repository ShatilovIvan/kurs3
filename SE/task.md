# Задание

## ЛР 1-2: BPMN-моделирование бизнес-процессов (EduCab №4)

### Вариант
10 — Библиотека (Бояркин, стр. 36)

### Предметная область
Основные процессы:
- Получение информации от поставщиков по изданиям
- Формирование заявок на пополнение библиотечного фонда
- Получение новых изданий
- Регистрация новых изданий
- Обслуживание абонентов

Особенности:
- План закупок изданий составляется вручную
- При первичном посещении регистратор создаёт карточку читателя и выдаёт абонемент (действителен год при условии посещения не реже 1 раза в 3 месяца)
- Если читатель не посещает библиотеку — абонемент аннулируется
- Записи о выданных книгах ведутся вручную

### Инструмент
Visual Paradigm (для BPMN-моделирования)

### Что нужно сделать
1. Выбрать 3 бизнес-процесса из предметной области
2. Написать текстовое описание каждого процесса по шаблону (`Шаблон описания бизнес-процесса.docx`):
   - Цель
   - Перечень действий с таймингом
   - Реализация процесса (общая длительность)
   - Сопровождение процесса
   - Результат процесса
   - Ресурсы
   - Исполнитель
   - KPI
3. Построить BPMN-модели для 3 процессов в Visual Paradigm
