Лабораторные работы по дисциплине «Разработка web-приложений»

Современный веб представляет собой разработку клиент-серверных приложений с интерфейсами, в которых зачастую необходимо отображать большое количество структурированных данных (маркетплейсы, панели управления, социальные сети и пр.)
Данные лабораторные работы направлены на изучение современных подходов к разработке web-интерфейсов, использующих большие объемы данных.

Лабораторная работа №1. HTML+CSS
В этой лабораторной работе предлагается разработать страницу для отображения данных в виде таблицы с использованием HTML и CSS. На данном этапе важно научиться правильно использовать семантическую верстку и стили.
Задание:
создать две html-страницы:
prizes.html – список нобелевских премий (категория, дата вручения, стоимость гранта);
laureats.html – список лауретов (имя/название, дата рождения/основания, число премий);
на каждой странице добавить шапку сайта (header), навигационное меню (nav) с гиперссылками сверху или сбоку страницы, основная часть (main), содержащая таблицу и подвал (footer);
для таблицы необходимо использовать такие теги, как table, thead, tbody, tr, th, td, а также настроить стили с помощью CSS (границы ячеек, чередование цвета строк, отступы внутри ячеек);
связать страницы гиперссылками (использовать тег <a> в навигационном меню, ведущий на страницу).
В результате выполнения лабораторной работы должны получиться две страницы для отображения данных в виде таблицы, связанные между собой гиперссылками.

Лабораторная работа №2. Реактивность
В данной работе предлагается использовать реактивные фреймворки для создания web-приложения. Основной задачей является разработка переиспользуемого реактивного компонента таблицы, использующего данные, передаваемые в качестве параметров. При реализации компонента разрешается использование библиотек компонентов. Переходы по созданным в предыдущей лабораторной работе страницам теперь должны выполняться с помощью роутера.
В результате выполнения лабораторной работы должно получиться SPA, содержащее два маршрута, отображающих переиспользуемый компонент таблицы.

Лабораторная работа №3. Стороннее API
В данной лабораторной работе предлагается использование стороннего API с целью получения данных для заполнения таблиц.
Необходимо реализовать единый класс-сервис для совершения запросов с использованием axios, а также классы-сервисы для получения данных через API (рекомендуется использовать https://www.nobelprize.org/about/developer-zone-2/). Таблицы должны поддерживать пагинацию, а также фильтрацию.

Лабораторная работа №4. Строгая типизация
В данной лабораторной работе необходимо ввести строгую типизацию получаемых через API данных. Для проверки типов поступаемых данных рекомендуется использовать библиотеку io-ts. Получаемые с помощью axios данные необходимо декодировать с помощью созданных кодеков. Для проверки соответствия данных кодеку предлагается создать функцию decodeOrThrow, использующую fp-ts для обработки Either.
В результате выполнения лабораторной работы должен получиться механизм строгой типизации данных, получаемых через API.

Лабораторная работа №5. Кеширование
В данной лабораторной работе нужно добавить возможность кеширования данных, получаемых с помощью API. Кеширование предполагает возможность работы приложения даже при отсутствующем интернет соединении. Для реализации необходимо проапгрейдить web-приложение до PWA и внедрить service-worker, который будет отвечать за логику кеша.
В результате выполнения полученное web-приложение должно иметь возможность отображать данные при отсутствии соединения и обновлять их при восстановлении подключения.
