Что такое HTML?
HTML — это язык разметки для структурирования и организации 
содержимого веб-страниц. Язык разметки — это система определения 
структуры, представления и назначения содержимого в цифровом 
документе, чтобы программы могли корректно интерпретировать и 
отображать его.
Разметка
Определяет элементы 
страницы с помощью тегов
Структура
Задаёт иерархию 
содержимого
HTML5
Текущий актуальный стандарт

Как работает HTML?
Теги — основа HTML
HTML использует теги — специальные команды в угловых скобках, которые 
сообщают браузеру, как отображать содержимое.
• Браузер читает теги и визуализирует страницу
• Поисковые системы используют теги для понимания структуры
• Теги бывают открывающими и закрывающими
Пример: <h1>Заголовок</h1> — тег верхнего уровня

Основные теги HTML
<p> — Абзац
Оборачивает блок текста в отдельный абзац
<a> — Ссылка
Создаёт гиперссылку на другую страницу или ресурс
<img> — Изображение
Вставляет изображение на страницу
<h1>…<h6> — Заголовки
Заголовки шести уровней важности
<title> — Название
Устанавливает название страницы во вкладке браузера
<div> и <span>
Контейнеры для группировки элементов

Атрибуты HTML
Что такое атрибут?
Атрибуты предоставляют дополнительную информацию об 
элементе. Каждый атрибут состоит из имени и значения.
<a href="https://example.com">Ссылка</a>
Атрибут href задаёт адрес ссылки. Без него тег <a> не будет 
знать, куда вести пользователя.
Часто используемые атрибуты
Атрибут Назначение
href Адрес ссылки
src Путь к изображению
alt Альтернативный текст
class CSS-класс элемента
id Уникальный 
идентификатор
style Встроенные стили

Семантический HTML
Семантический HTML использует теги, которые описывают смысл
содержимого, а не только его внешний вид. Семантическая разметка 
присваивает значение контенту, обозначая его структуру и назначение.
<header> и <nav>
Шапка сайта и навигационное меню
<main> и <article>
Основной контент и самостоятельные статьи
<footer>
Подвал страницы с дополнительной информацией
Семантические теги помогают браузерам, поисковым системам и улучшают 
доступность для людей с ограниченными возможностями.

Семантический vs Несемантический HTML
Почему это важно?
• SEO: Поисковики лучше понимают семантический код и ранжируют 
страницы выше
• Доступность: Скринридеры ориентируются по смысловым тегам
• Команда: Другим разработчикам легче читать код
• Стандарт: В современной разработке семантический HTML —
обязательная практика

HTML vs Языки программирования
HTML
Язык разметки — определяет 
структуру и внешний вид 
содержимого страницы. Статичен.
JavaScript
Язык программирования —
добавляет интерактивность и 
динамику прямо в браузере.
Python / PHP
Языки программирования —
выполняют логику, вычисления и 
обработку данных на сервере.
Языки программирования реагируют на ввод, принимают решения и выполняют задачи. HTML на это не способен 
— для интерактивности нужен JavaScript.

HTML в экосистеме веб-разработки
Три технологии работают вместе, создавая современные веб-приложения
HTML — Структура
Разметка и организация содержимого. 
Основа любой веб-страницы.
CSS — Стиль
Оформление и визуальное 
представление: цвета, шрифты, макет.
JavaScript — Интерактивность
Динамика и поведение: реакция на 
действия пользователя.
Изучение HTML — это первый шаг к освоению полного стека веб-разработки.
