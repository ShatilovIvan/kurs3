## Требования по ЛР

Общая тема: страницы и приложение для табличного отображения данных о Нобелевских премиях. ЛР строятся последовательно, одно приложение развивается от ЛР к ЛР.

### ЛР 1. HTML+CSS
- [ ] Две страницы: `prizes.html` (премии: категория, дата вручения, стоимость гранта) и `laureats.html` (лауреаты: имя/название, дата рождения/основания, число премий). Имя `laureats` — как в задании.
- [ ] На каждой странице `<header>`, `<nav>` с гиперссылками (сверху или сбоку), `<main>` с таблицей, `<footer>`.
- [ ] Таблица: `table`, `thead`, `tbody`, `tr`, `th`, `td`.
- [ ] CSS: границы ячеек, чередование цвета строк (zebra), внутренние отступы ячеек (padding).
- [ ] Страницы связаны через `<a>` в `nav`.
- [ ] Семантическая вёрстка.

### ЛР 2. Реактивность
- [ ] Реактивный фреймворк (какой именно — не указано).
- [ ] Переиспользуемый компонент таблицы, данные передаются через параметры (props).
- [ ] Разрешены библиотеки компонентов.
- [ ] Переходы между страницами из ЛР 1 — через роутер.
- [ ] Результат: SPA с двумя маршрутами, каждый показывает тот же компонент таблицы.

### ЛР 3. Стороннее API
- [ ] Данные для таблиц — из стороннего API; рекомендуется Nobel Prize API: https://www.nobelprize.org/about/developer-zone-2/
- [ ] Единый класс-сервис для HTTP-запросов на **axios**.
- [ ] Отдельные классы-сервисы для получения данных (премии, лауреаты).
- [ ] В таблицах есть пагинация и фильтрация.

### ЛР 4. Строгая типизация
- [ ] Строгая типизация данных из API; рекомендуется **io-ts** (кодеки).
- [ ] Ответы axios декодируются созданными кодеками.
- [ ] Функция `decodeOrThrow` на **fp-ts** (обработка `Either`): при несоответствии кодеку — исключение.
- [ ] Использование TypeScript явно не требуется, но подразумевается io-ts (**предположение**).

### ЛР 5. Кеширование
- [ ] Кеширование данных API, чтобы приложение работало без интернета.
- [ ] Приложение переведено в **PWA** (manifest — **предположение**, стандартная часть PWA) с **service worker**, который отвечает за логику кеша.
- [ ] Офлайн показываются закешированные данные; при восстановлении связи они обновляются.

## Практика 1 (HTML: введение в язык разметки)
- HTML — язык разметки для структуры веб-страниц; актуальный стандарт — HTML5.
- Теги открывающие и закрывающие; браузер визуализирует теги, поисковики по ним понимают структуру.
- Основные теги: `<p>`, `<a>`, `<img>`, `<h1>`…`<h6>`, `<title>`, `<div>`, `<span>`.
- Атрибуты: `href`, `src`, `alt`, `class`, `id`, `style`.
- Семантические теги: `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`; зачем они нужны: SEO, доступность (скринридеры), читаемость кода, стандарт индустрии.
- HTML (статичная разметка), JavaScript (интерактивность в браузере) и Python/PHP (серверная логика) — разные роли.
- Связка HTML (структура) + CSS (стиль) + JS (интерактивность).
- Таблицы и CSS в практике 1 не разбираются: для ЛР 1 нужны сверх материала.
