## Предметная область (вариант)

Чемпионат «Формула-1». Модель данных построена студентом в ЛР 1 в draw.io (вкладки: логическая модель IDEF1X, логическая модель Crow's Foot, физическая схема). Сущности:

| Сущность | Атрибуты | Связи |
|---|---|---|
| Команды | team_ID (PK), name, base | 1:N с Болидами и Пилотами |
| Болиды | car_ID (PK), model, year, team_ID (FK) | M:N с Запчастями через «Запчасти болидов» |
| Пилоты | driver_ID (PK), name, country, team_ID (FK) | — |
| Запчасти | part_ID (PK), name, type — справочник запчастей | M:N с Болидами через «Запчасти болидов» |
| Запчасти болидов | car_ID (PK, FK), part_ID (PK, FK) — какие запчасти стоят в болиде | N:1 с Болидами и с Запчастями |
| Спонсоры | sponsor_ID (PK), name, budget | 1:N с Гонками |
| Трассы | track_ID (PK), name, country, length_km | 1:N с Гонками |
| Гонки | race_ID (PK), name, date, track_ID (FK), sponsor_ID (FK) | 1:N с Результатами |
| Результаты гонок | race_ID (PK, FK), driver_ID (PK, FK), car_ID (FK), position, points | N:1 с Гонками, Пилотами и Болидами |

Физическая схема (типы PostgreSQL) получена для Команд (`INTEGER`, `VARCHAR(100)`) и Болидов (`INTEGER`, `VARCHAR(50)`); для остальных таблиц текст схемы был обрезан при пересылке, типы выбраны по аналогии (см. `progress.md`, «Открытые вопросы»).
