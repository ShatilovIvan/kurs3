# Studies 2026

Лабораторные работы по предметам.

## Структура

Каждая папка предмета:

```
<Предмет>/
├── task.md      # задание
├── progress.md  # таблица ЛР, текущий фокус, следующий шаг
├── log.md       # журнал действий (только дописывать)
├── materials/   # методички, методика рейтингового контроля, шаблоны, пособия
│   ├── INDEX.md # оглавление материалов: сроки, критерии, страницы
│   └── notes/   # текст PDF/DOCX для поиска
└── solution/    # решение
```

Правила ведения прогресса и журнала — в [CLAUDE.md](CLAUDE.md). Журнал по репозиторию в целом — [log.md](log.md).
