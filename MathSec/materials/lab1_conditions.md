# ЛР 1. Шифр Цезаря — условия

Источники: методичка «Математические основы защиты информации» (ОмГТУ, 2023), с. 5–12 и прил. 1 (с. 50); устные условия преподавателя (со слов студента, 2026-09-30); правила сдачи — со слов одногруппницы (чат группы, 16 сентября).

## Устные условия преподавателя

Проверка математики: спрашиваем ключ, пользователь вводит в консоль текст, выводим расшифрованный текст.

- Должна быть проверка корректности ввода ключа: ключ — исключительно целое число от 1 до 32. Если вводится целое отрицательное число, шифрование проводится с числом, сравнимым с введённым отрицательным по модулю 32.
- Текст пользователя — любой, но приводится к одному регистру; все символы, которых нет в таблице 1 (буквы), остаются неизменными.
- Должны быть реализованы:
  - функция шифрования;
  - функция расшифровки;
  - выполнение варианта: спрашиваем зашифрованную фразу и выводим результат. Ключ k не спрашиваем — перебираем варианты, пока не появятся осмысленные слова. Выводим значение k и вариант расшифровки с ним.
- В ответ — осмысленная фраза и значение ключа, при котором произошла расшифровка. Получится автор и произведение — без инициалов и без кавычек.
- Весь код лучше оформить в двух функциях.

## Задание по методичке (с. 8–9)

1. Изучить алгоритм шифрования простым постоянным сдвигом (шифр Цезаря).
2. Создать программу, позволяющую выполнить следующие действия:
   - 2.1. Шифрование текста, введённого с консоли, с помощью шифра Цезаря с ключом, задаваемым пользователем. Шифровать только символы русского алфавита; символы другого алфавита не изменять. Зашифрованный текст и ключ выводить в текстовый файл.
   - 2.2. Расшифрование текста, введённого с консоли, с помощью шифра Цезаря с ключом, задаваемым пользователем. Расшифрованный текст и ключ выводить в текстовый файл. Предусмотреть возможность сохранения в файле нескольких вариантов расшифровки при разных значениях ключа.
   - 2.3. Установление прямым полным перебором ключа, которым зашифрован текст варианта. В качестве ответа зашифровать тем же ключом фамилию автора и название произведения, из которого взята цитата.
3. По результатам оформить отчёт (прил. 1, с. 50).

Пример выполнения (с. 8):

```
ШИФР-ТЕКСТ (ШТ): шйльфавкж
РАСШИФРОВАННЫЙ ТЕКСТ (ОТ): асудьикто
КЛЮЧ: 24
АВТОР И ПРОИЗВЕДЕНИЕ (ОТ): грибоедовгореотума
ЗАШИФРОВАННЫЕ ФАМИЛИЯ И НАЗВАНИЕ (ШТ): ыиащжэьжъыжиэжклдш
```

Требования к программе (с. 9):

1. Текст программы оформляется по общепринятым правилам: удобно для чтения, с описанием всех функций, переменных и особо важных мест.
2. Интерфейс программы — любой удобный.
3. Среда разработки и язык программирования — произвольные.

## Математика (с. 5–7)

- Кодирование — таблица 1: а = 0, б = 1, …, я = 31; е и ё — один код 5; буквы в нижнем регистре; мощность алфавита m = 32.
- Шифрование: y = (x + k) mod 32. Расшифрование: x = (y − k) mod 32.
- По методичке ключ от 1 до m − 1 = 31 (с. 6), по устному условию — от 1 до 32 (k = 32 ≡ 0 не меняет текст).
