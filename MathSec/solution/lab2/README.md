# ЛР 2. Криптоанализ аффинного шифра — описание программы `affine.py`

Источники: устные условия преподавателя (`materials/lab2_conditions.md`); методичка «Математические основы защиты информации», ЛР 2, с. 13–23, отчёт — прил. 2 (с. 51); «Необходимые алгоритмы для МОЗИ26», п. 1 — расширенный алгоритм Евклида. Вариант 22.

Программа — консольное меню:

1. Проверка математики: 1 — расширенный алгоритм Евклида, 2 — элемент, обратный данному, 3 — решение сравнения ax ≡ b (mod m), 4 — решение системы ax + y ≡ b, cx + y ≡ d (mod m), 0 — назад.
2. Выполнение варианта — частотный анализ и взлом шифровки варианта (п. 2.4–2.6 методички, с. 18). Устные условия этого пункта преподаватель сообщит позже; сейчас он сделан по методичке.
3. Выход.

Комментариев в коде нет: описание всех функций, переменных и блоков — ниже.

## Математика

- Кодирование — таблица 2 методички (с. 13): а = 0 … я = 31, е и ё — один код 5, m = 32.
- Ключ — пара чисел k = (a, b); a взаимно просто с 32 (то есть нечётное), b — от 0 до 31 (с. 13).
- Шифрование (с. 14): y = (a·x + b) mod 32. Расшифрование: x = a⁻¹·(y − b) mod 32, где a⁻¹·a ≡ 1 (mod 32).
- Расширенный алгоритм Евклида находит d = НОД(a, b) и коэффициенты Безу x, y: a·x + b·y = d.
- Обратный элемент к a по модулю m существует только при НОД(a, m) = 1; тогда a·x + m·y = 1, и a⁻¹ = x mod m.
- Сравнение a·x ≡ b (mod m), d = НОД(a, m): если b не делится на d — решений нет; если d = 1 — одно решение x = a⁻¹·b mod m; если d > 1 и b делится на d — ровно d решений: x₀ + i·(m/d), i = 0 … d − 1, где x₀ — решение сравнения (a/d)·x ≡ b/d (mod m/d).
- Система a·x + y ≡ b, c·x + y ≡ d (mod m): вычитаем второе сравнение из первого, y сокращается: (a − c)·x ≡ b − d (mod m). Решаем это сравнение, для каждого x находим y = (b − a·x) mod m.
- Криптоанализ (с. 14–17): самые частые буквы шифр-текста соответствуют самым частым буквам русского языка (о, е, а, и, т, н — табл. 3, с. 15). Предположение E(p₁) = c₁, E(p₂) = c₂ даёт систему (p₁·a + b) ≡ c₁, (p₂·a + b) ≡ c₂ (mod 32) — это система из пункта 1.4, неизвестные в ней — ключ (a, b).

## Объяснение кода по блокам

### Блок 1. Подключение модуля и константы (строки 1–11)

- `Path` из стандартного модуля `pathlib` нужен, чтобы записывать файл результатов; сторонних библиотек программа не использует.
- `ALPHABET` — таблица 2 в виде строки: позиция буквы равна её коду. Буквы ё нет — она кодируется как е.
- `M` — модуль, длина алфавита, 32.
- `OUT_DIR` — папка программы; файл `variant.txt` создаётся в ней.
- `FREQ` — таблица 3 методички (с. 15): частота каждой буквы в русских текстах; ъ и ь, как в таблице, имеют одну частоту 0,014. Пробел («–» в таблице) не нужен: в шифровке пробелов нет.

### Блок 2. Расширенный алгоритм Евклида `ext_gcd(a, b)` (строки 14–24)

```python
def ext_gcd(a, b):
    sign_a = -1 if a < 0 else 1
    sign_b = -1 if b < 0 else 1
    a, b = abs(a), abs(b)
    x2, x1, y2, y1 = 1, 0, 0, 1
    while b > 0:
        q = a // b
        a, b = b, a - q * b
        x2, x1 = x1, x2 - q * x1
        y2, y1 = y1, y2 - q * y1
    return a, sign_a * x2, sign_b * y2
```

- Написан самостоятельно («ручками»), по алгоритму из «Необходимых алгоритмов для МОЗИ26», п. 1; встроенные `math.gcd` и `pow(a, -1, m)` не используются.
- Возвращает тройку `(d, x, y)`: d = НОД(a, b) и коэффициенты Безу, a·x + b·y = d.
- `sign_a`, `sign_b` — знаки исходных чисел. Алгоритм работает с неотрицательными числами, поэтому считаем для |a| и |b|, а в конце возвращаем знак коэффициентам: если |a|·x + |b|·y = d, то a·(−x) + b·y = d при отрицательном a.
- `x2, y2` — коэффициенты для текущего `a`, `x1, y1` — для текущего `b`. В начале a = a·1 + b·0 и b = a·0 + b·1, поэтому x2 = 1, x1 = 0, y2 = 0, y1 = 1.
- В цикле `q` — неполное частное, `a - q * b` — остаток. Пара (a, b) заменяется на (b, остаток), как в обычном алгоритме Евклида, а коэффициенты пересчитываются по той же формуле: новый = старый − q · предыдущий.
- Цикл кончается, когда остаток стал 0; тогда `a` — это НОД, `x2`, `y2` — его коэффициенты. Если a < b, первая итерация просто меняет числа местами (q = 0), поэтому условие a ≥ b из методички не обязательно.
- Пример: `ext_gcd(240, 46)` → (2, −9, 47): 240·(−9) + 46·47 = 2.

### Блок 3. Обратный элемент `inverse(a, m)` (строки 27–31)

- Вызывает `ext_gcd(a, m)`. Если НОД ≠ 1, обратного элемента нет — возвращает `None`.
- Иначе a·x + m·y = 1, то есть a·x ≡ 1 (mod m), и обратный элемент — `x % m`: наименьший неотрицательный вычет (отрицательный коэффициент Безу −7 по модулю 32 превращается в 25).

### Блок 4. Решение сравнения `solve_congruence(a, b, m)` (строки 34–41)

```python
a, b = a % m, b % m
d = ext_gcd(a, m)[0]
if b % d != 0:
    return []
m1 = m // d
x0 = inverse(a // d, m1) * (b // d) % m1
return [x0 + i * m1 for i in range(d)]
```

- Возвращает список всех решений от 0 до m − 1 (пустой — решений нет).
- Сначала a и b приводятся к вычетам по модулю m (отрицательные числа допустимы).
- `d` — НОД(a, m). Если b не делится на d — решений нет.
- Иначе сравнение делится на d: `m1` = m/d, (a/d) и m1 уже взаимно просты, решение `x0` = (a/d)⁻¹ · (b/d) mod m1.
- По модулю m решений ровно d: `x0`, `x0 + m1`, `x0 + 2·m1`, … При d = 1 список из одного числа.

### Блок 5. Решение системы `solve_system(a, b, c, d, m)` (строки 44–45)

`solve_congruence(a - c, b - d, m)` решает сравнение (a − c)·x ≡ b − d (mod m), полученное вычитанием; для каждого x вычисляется y = (b − a·x) mod m. Возвращает список пар `(x, y)`. Пустой список — система неразрешима; несколько пар — несколько решений (оба случая требует методичка, с. 17).

### Блок 6. Аффинный шифр `affine(text, a, b, mode)` (строки 48–58)

- Устроен как `caesar` в ЛР 1: `mode = 0` — шифрование y = (a·x + b) mod 32, `mode = 1` — расшифрование x = a⁻¹·(y − b) mod 32.
- `a_inv` — обратный к a элемент (через `inverse`), нужен для расшифрования.
- Текст приводится к нижнему регистру, ё — к е; символы не из таблицы 2 не меняются.

### Блок 7. Ввод целого числа `read_int(prompt, minimum=None)` (строки 61–72)

- Спрашивает число, пока не введено целое: при `abc`, `2.5`, пустой строке — «Ошибка: нужно ввести целое число.» Так выполняется проверка, что пользователь ввёл целые числа.
- `minimum` — наименьшее допустимое значение; для модуля m передаётся 2 (модуль 0 или 1 не имеет смысла).

### Блок 8. Выполнение варианта `crack()` (строки 75–127)

1. **Ввод шифровки (строки 76–80).** `raw` — строка пользователя; в `cipher` остаются только русские буквы, поэтому можно вставить шифровку с пробелами и переносами.
2. **Частотный анализ (строки 82–91), п. 2.4.** `counts` — сколько раз встречается каждая буква. `lines` — строки файла `variant.txt`: шифр-текст, длина и таблица частот (частота = количество / длина текста), как в шаблоне отчёта (прил. 2). `top_cipher` — 6 самых частых букв шифр-текста, `top_plain` — 6 самых частых букв русского языка по табл. 3.
3. **Предположения и системы (строки 93–107), п. 2.5.** Для каждой пары букв открытого текста (p₁, p₂) из `top_plain` и каждой упорядоченной пары разных букв шифр-текста (c₁, c₂) из `top_cipher` составляется система (x1·a + b) ≡ y1, (x2·a + b) ≡ y2 (mod 32) и решается функцией `solve_system` из пункта 1.4. Ключ берётся, только если a обратим (`inverse(a, M)` не `None`), — иначе расшифровать нельзя. `keys` — словарь «ключ (a, b) → первая система, которая его дала»; одинаковые ключи не повторяются.
4. **Поэтапный поиск ключа (строки 109–127), п. 2.6.** `order` — ключи, упорядоченные по сумме частот букв (табл. 3) в расшифрованном тексте: у осмысленного русского текста она наибольшая, поэтому правильный ключ обычно первый. Для каждого ключа программа печатает систему, ключ и расшифровку, дописывает их в `variant.txt` и спрашивает «Текст осмысленный?». Ответ `0` — следующий ключ, `1` — перебор прерывается, в файл дописываются «ВЕРНЫЙ КЛЮЧ» и «РАСШИФРОВАННЫЙ ТЕКСТ (ОТ)».

### Блок 9. Меню `main()` (строки 130–215)

- Внешний цикл `while True` печатает основное меню; `choice` — выбранный пункт. `1` — вложенное меню проверки математики, `2` — `crack()`, `3` — выход из цикла и программы, другое — сообщение об ошибке.
- Вложенный цикл печатает подменю, `sub` — выбранный пункт:
  - `1` (строки 150–159) — ввод a и b, отказ при a = b = 0 (НОД не определён), вывод d, коэффициентов Безу x, y и проверки a·x + b·y = d.
  - `2` (строки 161–172) — ввод a и m; если НОД(a, m) ≠ 1 — «элемента, обратного данному, не существует»; иначе коэффициент Безу x при a, при отрицательном x — наименьший неотрицательный вычет, обратный элемент и проверка a·a⁻¹ mod m = 1.
  - `3` (строки 174–186) — ввод a, b, m; печать d = НОД(a, m) и ответа в зависимости от d: решений нет / одно решение (d = 1) / d решений.
  - `4` (строки 188–203) — ввод пяти чисел a, b, c, d, m; печать сравнения после вычитания, НОД(a − c, m) и всех решений (x, y) либо «Система решений не имеет».
  - `0` — возврат в основное меню.

## Ответы на контрольные вопросы (с. 23)

1. **Преобразование для шифрования:** аффинное, y = (a·x + b) mod m, для русского алфавита m = 32.
2. **Преобразование для расшифрования:** обратное, x = a⁻¹·(y − b) mod m, где a⁻¹ — обратный к a элемент: a·a⁻¹ ≡ 1 (mod m).
3. **Требования к ключу:** k = (a, b), a взаимно просто с m (НОД(a, 32) = 1, то есть a нечётно — иначе a⁻¹ нет и расшифровать нельзя), 0 ≤ b ≤ m − 1. Всего ключей 16 · 32 = 512.
4. **Какой анализ нужен:** частотный анализ шифр-текста — определить самые часто встречающиеся буквы и сопоставить их с самыми частыми буквами языка (табл. 3: о, е, а, и, т, н).
5. **Какие предположения делаются:** что самые частые буквы шифр-текста — образы самых частых букв открытого текста (например, E(о) = c₁, E(е) = c₂). Каждое предположение даёт систему двух сравнений с неизвестными a и b; если система неразрешима или расшифровка бессмысленна, берут следующую по частоте букву.

## Как запустить в VS Code

### Один раз: установка

1. Установить Python 3 с https://www.python.org/downloads/. В установщике Windows поставить галочку **Add python.exe to PATH**.
2. Проверить: открыть терминал (Win + R → `cmd`) и выполнить `python --version` — должно вывести `Python 3.x.x`.
3. Установить VS Code с https://code.visualstudio.com/.
4. В VS Code открыть вкладку Extensions (Ctrl + Shift + X), найти **Python** (издатель Microsoft) и нажать Install.

1. File → Open Folder… → выбрать папку репозитория `studies_2026` (или сразу `MathSec/solution/lab2`).
