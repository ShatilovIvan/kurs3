# ЛР 1. Шифр Цезаря — описание программы `caesar.py`

Методичка «Математические основы защиты информации», с. 5–9 и прил. 1 (с. 50). Вариант 22.

Программа состоит из двух функций (`encrypt`, `decrypt`) и основного блока, который выполняет обе части задания: часть 1 — шифрование и расшифрование текста ключом пользователя (п. 2.1–2.2), часть 2 — взлом шифровки варианта полным перебором ключа (п. 2.3). Комментариев в коде нет: описание всех функций, переменных и блоков — ниже.

## Математика

Каждая русская буква заменяется числом по таблице 1 методички (с. 5): а = 0, б = 1, …, я = 31; буквы е и ё имеют один код 5. Размер алфавита m = 32.

- Шифрование (с. 6): y = (x + k) mod 32.
- Расшифрование (с. 7): x = (y − k) mod 32.

Здесь x — код буквы открытого текста, y — код буквы шифр-текста, k — ключ (величина сдвига).

## Объяснение кода по блокам

### Блок 1. Подключение модуля и константы (строки 1–5)

```python
from pathlib import Path

ALPHABET = "абвгдежзийклмнопрстуфхцчшщъыьэюя"
M = len(ALPHABET)
OUT_DIR = Path(__file__).parent
```

- `Path` из стандартного модуля `pathlib` нужен, чтобы записывать файлы результатов; сторонних библиотек программа не использует.
- `ALPHABET` — таблица 1 в виде строки: позиция буквы в строке равна её коду (`ALPHABET.index("а") == 0`, `ALPHABET.index("я") == 31`). Буквы ё в строке нет, потому что она кодируется так же, как е.
- `M` — модуль, длина алфавита, равна 32.
- `OUT_DIR` — папка, в которой лежит сама программа. Файлы `encrypted.txt`, `decrypted.txt`, `bruteforce.txt` создаются в ней, из какой бы папки ни запускали программу.

### Блок 2. Функция шифрования `encrypt(text, k)` (строки 8–15)

```python
def encrypt(text, k):
    result = ""
    for ch in text.lower().replace("ё", "е"):
        if ch in ALPHABET:
            result += ALPHABET[(ALPHABET.index(ch) + k) % M]
        else:
            result += ch
    return result
```

- Параметры: `text` — исходный текст, `k` — ключ. Возвращает шифр-текст.
- `text.lower()` приводит текст к одному (нижнему) регистру, как в таблице 1; `.replace("ё", "е")` — ё получает код буквы е.
- Цикл перебирает символы `ch` по одному. Если символ есть в таблице 1, берётся его код `ALPHABET.index(ch)`, к нему прибавляется ключ, результат берётся по модулю 32 (`% M`) — это формула y = (x + k) mod 32. По полученному коду из `ALPHABET` берётся буква шифр-текста.
- Любой другой символ (пробел, знак препинания, цифра, латиница) добавляется в `result` без изменений (п. 2.1 методички).
- Пример: `encrypt("яблоко", 3)` → я(31) + 3 = 34 mod 32 = 2 → «в»; результат «вдоснс».

### Блок 3. Функция расшифрования `decrypt(text, k)` (строки 18–25)

Устроена так же, как `encrypt`, только ключ вычитается: `(ALPHABET.index(ch) - k) % M` — формула x = (y − k) mod 32. Оператор `%` в Python при положительном модуле всегда даёт остаток от 0 до 31, поэтому отрицательная разность «заворачивается» в конец алфавита: а(0) − 3 = −3 mod 32 = 29 → «э».

### Блок 4. Запуск программы (строка 28)

`if __name__ == "__main__":` — код ниже выполняется, только когда файл запущен как программа. Если функции импортировать в другой файл (`from caesar import encrypt`), диалог с пользователем не запустится.

### Блок 5. Часть 1: ввод и проверка ключа (строки 29–43)

```python
while True:
    raw = input(...).strip()
    try:
        k = int(raw)
    except ValueError:
        print("Ошибка: ключ должен быть целым числом.")
        continue
    if 1 <= k <= M:
        break
    if k < 0:
        k = k % M or M
        print(...)
        break
    print(f"Ошибка: ключ должен быть от 1 до {M}.")
```

- `raw` — строка, введённая пользователем; `.strip()` убирает пробелы по краям.
- `int(raw)` превращает строку в целое число. Если ввели не целое число (`abc`, `2.5`, пустую строку), возникает `ValueError`: программа пишет ошибку и снова спрашивает ключ (`continue`).
- Ключ от 1 до 32 принимается (`break` — выход из цикла).
- Отрицательный ключ заменяется сравнимым с ним по модулю 32: `k % M` даёт остаток от 0 до 31 (−1 → 31, −33 → 31, −5 → 27). Если остаток 0 (например, −32), выражение `k % M or M` даёт 32, чтобы ключ остался в диапазоне 1–32.
- 0 и числа больше 32 отклоняются, ключ спрашивается снова.

### Блок 6. Часть 1: шифрование, расшифрование, запись в файлы (строки 45–53)

- `text` — текст пользователя (любой).
- `cipher = encrypt(text, k)` — шифр-текст; `plain = decrypt(cipher, k)` — расшифровка шифр-текста тем же ключом. Совпадение `plain` с введённым текстом (в нижнем регистре) показывает, что обе функции работают верно.
- Ключ, шифр-текст и расшифрованный текст печатаются в консоль и записываются: ключ и шифр-текст — в `encrypted.txt` (п. 2.1), ключ и расшифрованный текст — в `decrypted.txt` (п. 2.2). Кодировка файлов `utf-8`, чтобы русские буквы читались в любом редакторе.

### Блок 7. Часть 2: ввод шифровки и таблица частот (строки 55–62)

- `cipher` — зашифрованная фраза варианта; ключ при этом не спрашивается.
- `freq` — словарь «буква → частота в русских текстах, %». Он нужен только для подсказки: программа сама отмечает вариант, больше всего похожий на русский текст. В методичке осмысленный вариант выбирают глазами (с. 8), поэтому все варианты всё равно печатаются. Частоты букв — общие знания, в методичке их нет.

### Блок 8. Часть 2: полный перебор ключа (строки 63–71)

```python
for key in range(1, M):
    variant = decrypt(cipher, key)
    ...
    score = sum(freq.get(ch, 0) for ch in variant)
    if score > best_score:
        best_k, best_score = key, score
```

- `lines` — строки будущего файла `bruteforce.txt`.
- Цикл пробует все ключи `key` от 1 до 31 (k = 32 ≡ 0 по модулю 32 не меняет текст, поэтому не нужен; в шаблоне отчёта тоже k = 1…31, с. 50). Каждый вариант расшифровки `variant` печатается и добавляется в `lines` — это «несколько вариантов расшифровки при разных ключах» (п. 2.2).
- `score` — сумма частот букв варианта: у осмысленного русского текста много частых букв (о, е, а, и, н, т), и сумма получается наибольшей. `best_k` и `best_score` хранят лучший найденный ключ и его оценку.

### Блок 9. Часть 2: ответ и файл `bruteforce.txt` (строки 73–88)

- `answer` — расшифровка при лучшем ключе, печатается вместе с `best_k`. Студент проверяет глазами, что фраза осмысленная.
- `author_title` — фамилия автора и название произведения, которые вводит студент (без инициалов и кавычек). Из строки остаются только буквы таблицы 1 — пробелы и знаки удаляются, как в шифровке варианта.
- `author_title_cipher` — фамилия и название, зашифрованные найденным ключом: это ответ по п. 2.3.
- `lines[1:1] = [...]` вставляет после строки с шифр-текстом итоговые строки (расшифровка, ключ, автор и произведение, их шифр), и всё записывается в `bruteforce.txt`.

## Как запустить в VS Code

### Один раз: установка

1. Установить Python 3 с https://www.python.org/downloads/. В установщике Windows поставить галочку **Add python.exe to PATH**.
2. Проверить: открыть терминал (Win + R → `cmd`) и выполнить `python --version` — должно вывести `Python 3.x.x`.
3. Установить VS Code с https://code.visualstudio.com/.
4. В VS Code открыть вкладку Extensions (Ctrl + Shift + X), найти **Python** (издатель Microsoft) и нажать Install.

### Запуск

1. File → Open Folder… → выбрать папку репозитория `studies_2026` (или сразу `MathSec/solution/lab1`).
2. В проводнике слева открыть `MathSec/solution/lab1/caesar.py`.
3. Если внизу справа VS Code просит выбрать интерпретатор — нажать и выбрать установленный Python 3 (или Ctrl + Shift + P → **Python: Select Interpreter**).
4. Нажать треугольник ▷ **Run Python File** в правом верхнем углу редактора (или правый клик по коду → Run Python → Run Python File in Terminal). Внизу откроется терминал, программа начнёт задавать вопросы.

Другой способ — встроенный терминал (Ctrl + `):

```bash
cd MathSec/solution/lab1
python caesar.py
```

Программа ждёт ввода с клавиатуры (`input`), поэтому запускать её нужно именно в терминале. Если установлено расширение Code Runner, его кнопка выводит результат во вкладку Output, где ввод не работает; в этом случае использовать кнопку Run Python File или команду в терминале.
