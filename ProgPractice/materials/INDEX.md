## Методы и библиотеки из лекций

### Лекция 1. Методология CRISP-DM. Начало работы над ML-проектом
Слайды (И. Е. Бугаенко):
- CRISP-DM — стандартный жизненный цикл: от бизнес-задачи до внедрения.
- Базовый пайплайн: 0) описание задачи и признаков → 1) предобработка → 2) генерация признаков → 3) выбор моделей и метрик → 4) обучение, кросс-валидация, подбор гиперпараметров → 5) предсказания на новых данных и метрики.
- Шаг 1 (предобработка): загрузка и приведение типов (агрегация, парсинг дат, удаление столбцов), train/test, пропуски, кодирование категорий, выбросы, дисбаланс классов. Цель — получить данные для baseline-модели.
- Baseline — наивная модель на базово обработанных данных, нужна для оценки пользы предобработки.
- Советы по загрузке: проверять кодировку и разделитель CSV; `parse_dates`; `head()`, `info()`, сверка типов с таблицей семантики; `nunique()` для решения об удалении категорий; удалять признаки, неизвестные на момент прогноза; даты раскладывать на день/месяц/год; не допускать утечек.
- Ошибки train/test: сначала делить, потом обрабатывать только по train (перенося результат на test); учитывать временную структуру; `stratify=`; следить за размерами выборок.

Ноутбук `Лекция 1 - check_lifelines.ipynb` (пример: вероятность отказа насоса, цели `Дней в работе` + `Признак отказа`):
- Импорты в коде: `pandas as pd`, `numpy as np`, `typing as t`, `seaborn as sns`, `matplotlib.pyplot as plt`, `warnings` (`filterwarnings('ignore')`), `math`, `sklearn.model_selection.train_test_split`.
- В таблице библиотек заявлены, но в коде не импортируются: scikit-learn, scipy, missingno, lifelines, category_encoders, scikit-survival.
- `seed = 5; np.random.seed(seed)`.
- `pd.read_excel(..., parse_dates=[...])` + `pd.concat` двух файлов.
- Широкий df режется на 8 фрагментов, для каждого `head()`, `info()`, `nunique()`.
- Удаление id-признаков (много уникальных значений), текстового признака и признаков-утечек (дата демонтажа и т.п.); удаление признаков, вычисляемых из других (`corr()`).
- Даты → `_day`, `_month`, `_year`, исходный столбец удаляется; object → `astype(str)`.
- `train_test_split(df, shuffle=True, stratify=df['Признак отказа'], random_state=seed, test_size=0.15)`.
- В ячейке 9 — таблица замечаний валидатора (TODO / приоритет / комментарий): образец того, за что снимают (путаница 0/1 в таргете, мало данных в test, медиана vs среднее, «выводить графики и смотреть глазами»).

### Лекция 2. Обработка пропущенных значений. Кодирование категориальных признаков
Слайды:
- Без обработки пропусков и категорий большинство моделей не обучится.
- 4 подхода к пропускам: интерпретация (бизнес-правило: `'NaN'` как категория, 0 / −1 / 9999), статистические (mean/median), машинные (MICE, KNNImputer, без использования target), по соседним значениям.
- Заполнение константой искажает распределение; выбор значения — по гистограммам до и после + **KL-дивергенция** (чем ближе к 0, тем лучше).
- Правила: признак с >50–70 % пропусков можно удалить; строки с пропуском в target удалять; строки с высокой концентрацией пропусков удалять; анализировать пропуски, даже если в train их нет (они могут быть в test); сравнивать статистическое и модельное заполнение по метрикам моделей.
- Виды категорий: равнозначные, порядковые, смешанные.
- Кодировщики: One-Hot (прост, но раздувает размерность при >10 категориях), Label (компактен, но задаёт произвольный порядок, плох для линейных моделей), Target (учитывает связь с целью, риск переобучения; есть слайд «Стратегии Target Encoder»).

Ноутбук `Лекция 2 - missings_cat.ipynb` (тот же пример насосов; ячейки 0–98 повторяют Л1, дальше новое):
- `import missingno as msgn; msgn.matrix(df[nan_cols])` — визуализация пропусков.
- Удаление строк: доля пропусков в строке > 75-го перцентиля (≈5 %) → `drop` (до train/test).
- Проверка, что все категории есть в train: `df[obj].nunique() - X_train[obj].nunique()`.
- `sklearn.preprocessing.OneHotEncoder(sparse_output=False, drop='first', handle_unknown='ignore')`: fit на train, transform на test, имена через `get_feature_names_out`.
- Числовые признаки: `select_dtypes(exclude='object')`; пропуски считаются отдельно в train и test; `np.union1d` столбцов с пропусками.
- MICE: `from sklearn.experimental import enable_iterative_imputer`, `IterativeImputer(max_iter=100, random_state=seed)`; качество — **NRMSE** (RMSE/σ) на искусственно замаскированных 20 %; интерпретация: <0.1 очень хорошо, <0.2 хорошо, <0.3 средне, ≥0.3 плохо. В примере MICE признан неприменимым.
- Анализ распределений: `calc_bins` (формула Стерджеса), `calc_kl_divergence` через `scipy.stats.entropy` по `np.histogram`, `draw_hist` (`sns.histplot(np.log(x), kde=True, stat='density')`), `test_density_fillna` перебирает `0 / mean / median`.
- Итог — словарь `fillna_rule` (значения по train) → `fillna` для train и test.
- Сборка `X_train_oh = concat(one_hot, numeric)`; финальный блок **Production** (ячейки 310–322) повторяет весь пайплайн чистым кодом.
- Выбросы в примере сознательно не удаляются (они отражают реальную работу оборудования).
- Не использованы в коде, хотя есть на слайдах или в таблице библиотек: KNNImputer, LabelEncoder, TargetEncoder, `category_encoders`, lifelines.

- ЛР 2–5 и ДЗ на wiki не описаны; лекции 3–5 не выложены. Критерии для них: не найдено.
- Вариант подгруппы не выбран (`../task.md`: «Мой вариант: _не выбран_»).

- Под pandas 3.x строковые столбцы получают dtype `str`, а не `object`. `select_dtypes('object')` из ноутбуков лекций пока их захватывает, но выдаёт `Pandas4Warning` (поведение устарело). Надёжнее писать `include=['object', 'str']` или зафиксировать pandas 2.x.
